# Bundled PDF fonts

Noto Serif Regular and Bold provide the serif Vietnamese typography used by the supplied paper rental contract layout. Static TrueType fonts are embedded as subsets by PDFBox 3.0.8; no host-installed fonts or runtime downloads are required.

Source: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSerif

- `NotoSerif-Regular.ttf`
- `NotoSerif-Bold.ttf`
- License: `NotoSerif-OFL.txt` (SIL Open Font License 1.1, from the source repository's `LICENSE`).

Existing Noto Sans fonts and `OFL.txt` are retained for other consumers.
